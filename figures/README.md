# Figures

`reference/` contains seven paper figures as PDF and PNG, with Draw.io source for the three conceptual figures.

The plotting command regenerates the four data figures and two additional calibration figures from task observations and recomputed effects. It writes PDF, PNG, and the median/IQR plotting values to the selected output directory. Appearance can vary with plotting-library versions while the statistical values remain checked against the distributed references.

Conceptual diagrams can be edited and exported using Draw.io. All rendered figures use Times New Roman. Figure assets are licensed under CC BY 4.0; plotting code uses Apache-2.0.
